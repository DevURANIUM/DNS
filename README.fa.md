## 🏛️ معماری سیستم و نحوه عملکرد

پروژه **DNS** با استراتژی تفکیک مسیر کار می‌کند و شبکه را میان سرورهای **رله (داخل ایران)** و سرورهای **خروج (خارج از کشور)** پیوند می‌دهد:

```text
  دستگاه کلاینت (کنسول بازی / PC / گوشی)
                    │
                    │ ۱. پرسش استعلام DNS
                    ▼
         ┌────────────────────┐
         │  سرور رله (ایران)  │
         │   (dnsmasq فعال)   │
         └─────────┬──────────┘
                   │
         ┌─────────┴────────────────────────┐
         ▼                                  ▼
 [دامنه‌های مسدود یا تحریم]           [دامنه‌های عادی و وبسایت‌های داخلی]
         │                                  │
         │ آی‌پی رله بازگردانده می‌شود         │ پاسخ مستقیم از سرورهای بالادست
         ▼                                  ▼
┌───────────────────┐              ┌───────────────────┐
│       Nginx       │              │  ارتباط مستقیم و  │
│    (SNI Proxy)    │              │   بدون افت پینگ   │
└─────────┬─────────┘              └───────────────────┘
          │
          │ ۲. تونل مستقیم و خام TCP
          ▼
┌───────────────────┐
│ سرور خروج (خارج)  │
│ (انتقال شفاف داده)│
└─────────┬─────────┘
          │
          │ ۳. تبادل با سرویس نهایی
          ▼
[پلی‌استیشن / استیم / داکر و ...]
```

### مزیت‌های اساسی انتقال شفاف بدون شکستن TLS:
1. **امنیت مطلق اطلاعات (No TLS Termination):** سرور رله هرگز نشست‌های رمزنگاری کاربر را بازگشایی نمی‌کند؛ تنها سرآیند SNI در لایه اولیه خوانده شده و جریان داده‌ها به شکل خام به سرور خارج تونل می‌شود.
2. **بدون نیاز به گواهینامه روت (Root CA):** نیازی به نصب پروفایل یا دستکاری امنیتی در دستگاه‌های کاربران نیست.
3. **حفظ ترافیک ملی و پینگ بهینه:** سرویس‌های غیرتحریمی و وبسایت‌های مستقر در ایران به صورت مستقیم تبادل شده و پهنای‌باند سرور خارجی مصرف نمی‌گردد.

## ✨ ویژگی‌های برجسته

- **🎮 بهینه‌سازی شده برای جامعه گیمینگ:**
  - پشتیبانی از شبکه‌های مطرح شامل پلی‌استیشن (PSN)، ایکس‌باکس لایو، استیم، اپیک گیمز، الکترونیک آرتز (EA)، بتل‌نت، رایوت گیمز و پابجی موبایل.
  - سرویس STUN/TURN تعبیه‌شده جهت حفظ کامل وضعیت NAT Type (پشتیبانی از Open/Moderate) برای گفتگوهای صوتی (Party Voice) و بازی‌های چندنفره آنلاین.
  - دانلود بسته‌های پرحجم بازی‌ها از طریق CDNهای بدون تحریم به شکل مستقیم برای حفظ حداکثر سرعت.

- **⚡ فایروال و سهمیه‌بندی هسته لینوکس (`nftables`):**
  - کنترل لیست سفید آدرس‌های مجاز در لایه کرنل بدون سربار پردازشی بر CPU.
  - محاسبه دقیق ترافیک با شمارنده‌های اتمیک هسته و قطع خودکار دسترسی پس از پایان سهمیه.
  - محدودسازی داینامیک پهنای‌باند با ترکیب الگوریتم‌های پیشرفته `htb` و `fq_codel`.

- **🎨 پنل‌های وب مدرن با طراحی نوین Glassmorphism:**
  - **پنل اپراتور (مدیریت):** رصد لحظه‌ای بار ترافیکی سرورها، صدور و مدیریت حساب‌ها، تعریف بسته‌های اعتباری یا ماهانه، جابجایی دستی یا خودکار رله‌ها میان نودهای مختلف خروج.
  - **پنل مشترک (کاربر):** ثبت آسان آدرس IP به صورت خودکار یا دستی (پشتیبانی کامل از اعداد فارسی و انگلیسی)، مشاهده روزهای باقیمانده، میزان مصرف و آدرس‌های DNS قابل کپی.
  - تایپوگرافی چشم‌نواز با فونت بومی `Vazirmatn` و کدنویسی `JetBrains Mono`، با پشتیبانی بی‌نقص از تم تیره و روشن.

- **🛡️ پایداری بالا در شرایط اختلال شبکه:**
  - تونل‌بندی منعطف با چند روش جایگزین هنگام بروز اختلال در ارتباطات مستقیم بین رله و خارج.
  - پشتیبانی از استندبای (Standby Node) برای بازیابی اضطراری و کلون خودکار پیکربندی‌ها در چند ثانیه.

- **📦 بدون نیاز به پکیج‌های حجیم یا خارجی:**
  - نصب خودکفا و سبک، بدون نیاز به داکر یا پیش‌نیازهای سنگین، تنها با اتکا به بسته‌های رسمی دبیان/اوبونتو.

## 🔌 پورت‌های مورد استفاده در شبکه

این سیستم از درگاه‌های استانداردی روی سرور استفاده می‌کند؛ بنابراین پورت پنل مدیریت نباید با این پورت‌ها تداخل داشته باشد:

| پورت | پروتکل | هدف کاربردی |
|---|---|---|
| **22** | TCP | دسترسی SSH جهت مدیریت سیستم |
| **53** | UDP/TCP | سرویس‌دهی درخواست‌های نام دامنه (DNS) |
| **80** | TCP | هدایت درخواست‌های HTTP و پکیج‌های کنسول‌ها |
| **443** | TCP | پراکسی امن SNI برای ارتباطات HTTPS |
| **8443** | TCP | سینک دوره‌ای امن میان رله و سرور خروج |
| **8446** | TCP | ارتباطات تونل‌های پایدار رله و نودها |
| **3478** | UDP/TCP | پروتکل STUN/TURN جهت تثبیت NAT Type کنسول‌ها |

> [!NOTE]
> برای پنل مدیریت، یک پورت آزاد و مجزا (مانند **9443**) پیشنهاد می‌شود تا با هیچ‌کدام از درگاه‌های فوق تداخل نداشته باشد.

## 🛠️ نقش‌های سرور در شبکه

1. **سرور خروج (Exit Node):** این سرور باید در خارج از کشور قرار داشته باشد و نقش پلی برای اتصال به وبسایت‌های تحریم‌کننده را ایفا می‌کند. ابتدا این سرور را نصب کنید و توکن جفت‌سازی (Pairing Token) نمایش داده‌شده را بردارید.
2. **سرور رله (Relay Node):** سرور مستقر در دیتاسنتر داخل کشور که با کاربران مستقیماً در ارتباط است و درخواست‌ها را پالایش می‌کند. هنگام نصب رله، آی‌پی سرور خروج و توکن مرحله قبل را وارد نمایید.
3. **نودهای استندبای / لبه (Standby & Edge Nodes):** برای پایداری و مقیاس‌پذیری می‌توانید چندین سرور خروج دیگر به عنوان نود اضافه کرده و در پنل مدیریت مدیریت کنید.

## 💻 پنل‌های تحت وب

- **پنل مدیریت (Admin Panel):** مدیریت جامع اشتراک‌ها، تعریف پلن‌ها و نظارت بر سلامت شبکه:
  `http://[IP-یا-دامنه]:[PORT]/[SECRET_PATH]`
- **پنل کاربری (Customer Portal):** آدرس ساده برای ثبت سریع آی‌پی کلاینت بدون نیاز به ورود نام‌کاربری:
  `http://[IP-یا-دامنه]:[PORT]/`

## ⌨️ راهنمای دستورات خط فرمان (CLI)

برای مدیریت سریع سرویس‌ها از طریق ترمینال لینوکس می‌توانید از ابزارهای داخلی استفاده نمایید:

```sh
smartdns status
smartdns list
smartdns find spotify
smartdns add example.com
smartdns del example.com
smartdns bypass api.example.com
smartdns test example.com
smartdns-rules
smartdns-rules show test
smartdns-rules check gemini.google.com
smartdns-access
smartdns-access username ali
smartdns-access port 9443
smartdns-access path [new]
smartdns-access password [new]
smartdns-access rotate
smartdns-acl list
smartdns-acl usage 5.188.44.19
smartdns-acl add 5.188.44.19 ali
smartdns-acl del 5.188.44.19
smartdns-acl reset <ip>|--all
smartdns-acl enforce status
smartdns-acl enforce on
smartdns-acl enforce off
smartdns-acl save
smartdns-shape list
smartdns-shape off
smartdns-cert panel.example.com
```

## 🤖 سرویس ربات تلگرام

برای اتوماسیون امور مشتریان، سورس کد آماده ربات تلگرام در پوشه `examples/telegram-bot/` مهیا شده است:

1. کپی و ویرایش فایل تنظیمات:
   ```bash
   cp examples/telegram-bot/bot.env.example examples/telegram-bot/bot.env
   nano examples/telegram-bot/bot.env
   ```
2. راه‌اندازی و شروع به کار سرویس:
   ```bash
   sudo systemctl enable --now dns-bot.service
   ```
