# به‌روزرسانی پنل‌ها

- بازطراحی پنل مدیریت، ورود، ثبت‌نام و حساب کاربر؛ سازگار با موبایل و راست‌به‌چپ.
- فونت متغیر وزیرمتن به‌صورت محلی، با مجوز OFL؛ بدون درخواست به CDN.
- تم روشن و تاریک با حفظ انتخاب در همان مرورگر.
- جست‌وجوی جدول‌ها با پشتیبانی از حروف فارسی/عربی و اعداد فارسی، شمارنده نتایج و فیلتر وضعیت کاربران.
- بخش «نیازمند بررسی» برای کاربران منتظر پلن، حساب‌های نیازمند تمدید و رسیدهای معطل.
- کپی DNS با اعلام نتیجه، راهنمای اتصال، نمایش/پنهان‌سازی رمز و بهبود استفاده با کیبورد.
- حفظ سهمیه اعشاری در فرم؛ رد مقادیر منفی، نامتناهی و خارج از محدوده؛ اعتبارسنجی کامل فرم پیش از تغییر سهمیه.

## ساخت و پیش‌نمایش

برای تغییر ظاهر، فایل‌های `assets/ui/panel.css` و `assets/ui/panel.js` را ویرایش کنید.

```sh
python tools/build-installer.py
python tools/test-ui-regressions.py
python tools/preview-ui.py
python -m http.server 8765 --bind 127.0.0.1 --directory docs/preview
```

صفحات نمونه روی آدرس‌های `/admin.html`، `/users.html`، `/user.html`، `/login.html` و `/signup.html` قرار دارند.
این صفحات با داده ساختگی ساخته می‌شوند و برای نمایش هستند؛ لینک‌های عملیاتی و عملیات سرور در پیش‌نمایش فعال نیستند.

فایل `doctor-dns.sh` از منابع جدید بازسازی شده است. برای اعمال روی سرور، نسخه همین فایل را طبق روند آپگرید پروژه اجرا کنید. این تغییرات به‌صورت محلی آماده شده‌اند و روی سرور واقعی نصب نشده‌اند.
